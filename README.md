## Selected work

<table>
<tr>
<td width="50%" valign="top">

### [PyCurb](https://github.com/fore-site/pycurb)
**Rate limiting for Python web apps**

- 5 algorithms, in-memory or Redis storage, sync and async support, dynamic rule updates, composite multi-tier limits.
- Atomic distributed limiting with Redis Lua scripts; adapters for FastAPI, Flask and Django.
- CI/CD with GitHub Actions, so only tested changes ship.
- **Benchmarked at 25,000+ requests/second** with sub-millisecond latency. Estimated 80% cut in endpoint integration time.

</td>
<td width="50%" valign="top">

### [Metrika](https://github.com/fore-site/metrika)
**Web analytics platform**

- Event ingestion with bot filtering and location enrichment.
- Daily aggregation of page views, referrers, countries, regions, cities, devices, browsers and operating systems.
- Timezone-aware stats and session metrics: bounce rate, views per visit, duration.
- REST reporting endpoints with Swagger docs and a Prometheus metrics dashboard.

</td>

### [Tiber](https://github.com/fore-site/tiber)
**Intelligent notification delivery** (in development)

- Decides when a message goes out, how urgent it is and what it says.
- Event-driven on RabbitMQ: retries, dead-lettering, idempotent processing, provider failover.
- Synthetic data simulator for testing decisions on realistic engagement data.

</td>
<td width="50%" valign="top">

### [Pulp](https://github.com/fore-site/pulp)
**Comic and manga store**

- Django, PostgreSQL and Redis.
- Removed N+1 query patterns on a catalog of 100K+ SKUs.
- **Response time down from ~2.3s to 78ms** through query optimization, indexing and caching.
- Paystack payments with webhook testing and transaction-reference verification.
